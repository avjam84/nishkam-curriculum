G5.1 Angle Properties of Triangles and Quadrilaterals

Key definitionAngles in a triangle sum to 180°; in a quadrilateral to 360°.

Core knowledge. Isosceles triangles have two equal base angles. Give reasons using correct geometric language. This builds directly on the definition above: learn the definition so you can quote it, then practise the technique until it is automatic, because multi-step questions combine angle properties of triangles and quadrilaterals with other topics in this block.

G5.3 Interior Angles in Polygons

Key definitionThe sum of interior angles of an n-sided polygon is (n − 2) × 180°.

Core knowledge. Each interior angle of a regular polygon = (n − 2) × 180° ÷ n. This builds directly on the definition above: learn the definition so you can quote it, then practise the technique until it is automatic, because multi-step questions combine interior angles in polygons with other topics in this block.

G5.4 Exterior Angles in Polygons

Core knowledge. For a regular polygon, n = 360° ÷ exterior angle. Interior + exterior = 180°. 4. Common Mistakes

  1. Using Pythagoras to find a shorter side by adding. Why it is wrong: In a right-angled triangle, a² + b² = c² where c is the hypotenuse. To find a shorter side, subtract: a² = c² − b².
  2. Calculator in radians mode. Why it is wrong: SOH CAH TOA: sin θ = opp/hyp, cos θ = adj/hyp, tan θ = opp/adj. Label sides relative to the angle; use inverse functions to find angles. Calculator must be in degrees.
  3. Labelling opposite/adjacent from the wrong angle. Why it is wrong: Angles in a triangle sum to 180°; in a quadrilateral to 360°. Isosceles triangles have two equal base angles. Give reasons using correct geometric language.
  4. Writing 'Z angles' instead of 'alternate angles'. Why it is wrong: Alternate angles are equal, corresponding angles are equal, co-interior angles sum to 180°. Write the full reason, e.g. 'alternate angles are equal', not 'Z angles'.
  5. Using the interior angle sum to find n for a regular polygon instead of exterior 360° ÷ angle. Why it is wrong: Exterior angles of any polygon sum to 360°. For a regular polygon, n = 360° ÷ exterior angle. Interior + exterior = 180°.

6. Colour-Coded Model Answers

To be confirmed by teacherThe assessment objectives AO1–AO3 and their colour-coding, and the mark allocations shown on model answers, are national GCSE/A level Mathematics conventions, not from the curriculum map.
AO1 Use and apply standard techniquesAO2 Reason, interpret and communicate mathematicallyAO3 Solve problems within mathematics and in other contexts

Question type 1: Calculate / Find 4 marks

A ladder 6.5 m long leans against a wall with its foot 2.5 m from the wall. How high up the wall does it reach, and what angle does it make with the ground?

Show model answer
AO1 — Hypotenuse 6.5 m: h² = 6.5² − 2.5² = 42.25 − 6.25 = 36.
AO1 — h = 6 m.
AO3 — Angle with ground: cos θ = 2.5 / 6.5, so θ = cos⁻¹(0.3846…) = 67.4° (1 d.p.).
AO2 — Check with tan: tan θ = 6/2.5 = 2.4 gives 67.4° ✓, therefore both results agree.
What makes this workEach step is written on its own line, so method marks (AO1) are earned before the final answer. The last step checks or interprets the result (AO2), which is where full marks are usually secured. The chain of reasoning uses connectives such as "therefore", "which means" and "this shows that".

Question type 2: Show that / Prove 4 marks

Show clearly that the answer to the question above follows from the given information: Check with tan: tan θ = 6/2.5 = 2.4 gives 67.4° ✓, therefore both results agree.

Show model answer
AO2 — State what is given and what must be shown, so the examiner can follow the argument.
AO1 — Hypotenuse 6.5 m: h² = 6.5² − 2.5² = 42.25 − 6.25 = 36.
AO1 — h = 6 m.
AO3 — Angle with ground: cos θ = 2.5 / 6.5, so θ = cos⁻¹(0.3846…) = 67.4° (1 d.p.).
AO2 — Check with tan: tan θ = 6/2.5 = 2.4 gives 67.4° ✓, therefore both results agree.
AO2 — Concluding statement: this shows that the required result holds, as given.
What makes this workIn a "show that" question the answer is given, so the marks are for the working. No step is skipped, the argument starts from the given facts, and it ends with an explicit concluding sentence.

Question type 3: Explain / Interpret 2 marks

A student made this error: "Using Pythagoras to find a shorter side by adding." Explain why the student is wrong and state the correct approach.

Show model answer
AO2 — The student is wrong because the correct rule is: In a right-angled triangle, a² + b² = c² where c is the hypotenuse.
AO1 — Correct approach: To find a shorter side, subtract: a² = c² − b².
What makes this workThe answer names the error, gives the correct rule as the reason ("because"), and then states the correct method. Explanations without a reason score at most one mark.

Evaluation

9. Judgement Phrases for Evaluation

In mathematics, "evaluation" means justifying, checking and commenting on answers. Adapt these sentences:

  1. This answer is reasonable because an estimate using values rounded to 1 significant figure gives a result of the same size.
  2. Since the rule for angle properties of triangles and quadrilaterals has been applied correctly at each step, the final result follows.
  3. This method is more efficient than the alternative because it reaches the answer in fewer steps with less chance of arithmetic error.
  4. The answer is only an approximation, because values were rounded during the calculation; working to full accuracy would give a more reliable result.
  5. The model assumes conditions that may not hold in reality, so the answer should be treated as an estimate rather than an exact value.
  6. Substituting the answer back into the original problem confirms it, which shows that no error has been made.
  7. Using trigonometry is appropriate here because the question gives exactly the information that this technique requires.
Reminders

10. Exam Reminders

To be confirmed by teacherReminders about marks, accuracy conventions and formula sheets are general exam conventions, not from the curriculum map; check them against the confirmed exam board.
  1. Label hyp, opp, adj first.
  2. Degrees mode.
  3. Always give a geometric reason for each angle step.
  4. Round only at the final answer.
  5. Read the command word: 'show that' needs every step; 'write down' needs no working.
  6. Give answers to the accuracy requested; if none is stated, use 3 significant figures for non-exact answers.
  7. Never round in the middle of a calculation; keep full calculator values until the end.
  8. If you get stuck, write down the formula or the first step anyway: method marks are independent of the final answer.
