G1.1 Place Value

Key definitionThe value of a digit depends on its position: in 3.47 the 4 is worth 4 tenths.

Core knowledge. Multiplying by 10ⁿ moves digits n places left; dividing moves them right. The decimal point does not move. This builds directly on the definition above: learn the definition so you can quote it, then practise the technique until it is automatic, because multi-step questions combine place value with other topics in this block.

4. Common Mistakes

  1. Writing 0.0049 as 0.0048 by truncating instead of rounding. Why it is wrong: Rounding replaces a number with a nearby simpler value to a stated degree of accuracy. For significant figures, count from the first non-zero digit: 0.004862 to 2 s.f. is 0.0049.
  2. Treating a⁻² as −a² — a negative index gives a reciprocal. Why it is wrong: a⁰ = 1, a⁻ⁿ = 1/aⁿ, a^(1/n) = ⁿ√a, a^(m/n) = (ⁿ√a)ᵐ. Evaluate fractional indices root first: 8^(2/3) = (∛8)² = 4. Negative index means reciprocal, not a negative answer.
  3. Leaving standard form as 23 × 10⁴ instead of 2.3 × 10⁵. Why it is wrong: A number written as A × 10ⁿ where 1 ≤ A < 10 and n is an integer. When multiplying, multiply the A values and add the powers, then readjust so 1 ≤ A < 10.
  4. Using HCF when the problem (e.g. buses arriving together) needs LCM. Why it is wrong: A number written as A × 10ⁿ where 1 ≤ A < 10 and n is an integer. When multiplying, multiply the A values and add the powers, then readjust so 1 ≤ A < 10.
  5. Adding surds that are not like terms: √2 + √3 ≠ √5. Why it is wrong: A surd is an irrational root such as √2 that cannot be simplified to an integer. √(ab) = √a × √b. Rationalise 1/√a by multiplying by √a/√a.

Question type 1: Calculate / Find 4 marks

Find the HCF and LCM of 84 and 90.

Show model answer
AO1 — 84 = 2² × 3 × 7 and 90 = 2 × 3² × 5.
AO1 — Shared primes at lowest powers: 2 × 3, so HCF = 6.
AO2 — All primes at highest powers: 2² × 3² × 5 × 7, which means LCM = 1260.
AO2 — Check: HCF × LCM = 6 × 1260 = 7560 = 84 × 90 ✓, therefore both answers are consistent.
What makes this workEach step is written on its own line, so method marks (AO1) are earned before the final answer. The last step checks or interprets the result (AO2), which is where full marks are usually secured. The chain of reasoning uses connectives such as "therefore", "which means" and "this shows that".

Question type 2: Show that / Prove 4 marks

Show clearly that the answer to the question above follows from the given information: Check: HCF × LCM = 6 × 1260 = 7560 = 84 × 90 ✓, therefore both answers are consistent.

Show model answer
AO2 — State what is given and what must be shown, so the examiner can follow the argument.
AO1 — 84 = 2² × 3 × 7 and 90 = 2 × 3² × 5.
AO1 — Shared primes at lowest powers: 2 × 3, so HCF = 6.
AO2 — All primes at highest powers: 2² × 3² × 5 × 7, which means LCM = 1260.
AO2 — Check: HCF × LCM = 6 × 1260 = 7560 = 84 × 90 ✓, therefore both answers are consistent.
AO2 — Concluding statement: this shows that the required result holds, as given.
What makes this workIn a "show that" question the answer is given, so the marks are for the working. No step is skipped, the argument starts from the given facts, and it ends with an explicit concluding sentence.

7. Sophisticated Concepts

Mathematics has no specification list of named theories in the business sense, so this section lists the named results and techniques from the curriculum map that this block relies on and where they fit:

  • Place Value: Multiplying by 10ⁿ moves digits n places left; dividing moves them right. The decimal point does not move.
  • Decimals: To multiply decimals, multiply as integers then place the decimal point so the answer has as many decimal places as the factors combined.
  • Rounding: For significant figures, count from the first non-zero digit: 0.004862 to 2 s.f. is 0.0049.
  • Estimation: State whether your estimate is an over- or underestimate by checking which way each value was rounded.
  • HCF & LCM: Write each number as a product of prime factors. HCF = product of shared primes (lowest powers); LCM = product of all primes (highest powers).
  • Zero, Negative and Fractional Indices: Evaluate fractional indices root first: 8^(2/3) = (∛8)² = 4. Negative index means reciprocal, not a negative answer.
  • Standard Form: When multiplying, multiply the A values and add the powers, then readjust so 1 ≤ A < 10.
  • Surds: √(ab) = √a × √b. Rationalise 1/√a by multiplying by √a/√a.
  • Combinations: Extend to any number of independent choices by multiplying all the option counts.

Evaluation

9. Judgement Phrases for Evaluation

In mathematics, "evaluation" means justifying, checking and commenting on answers. Adapt these sentences:

  1. This answer is reasonable because an estimate using values rounded to 1 significant figure gives a result of the same size.
  2. Since the rule for place value has been applied correctly at each step, the final result follows.
  3. This method is more efficient than the alternative because it reaches the answer in fewer steps with less chance of arithmetic error.
  4. The answer is only an approximation, because values were rounded during the calculation; working to full accuracy would give a more reliable result.
  5. The model assumes conditions that may not hold in reality, so the answer should be treated as an estimate rather than an exact value.
  6. Substituting the answer back into the original problem confirms it, which shows that no error has been made.
  7. Using combinations is appropriate here because the question gives exactly the information that this technique requires.
Reminders

10. Exam Reminders

To be confirmed by teacherReminders about marks, accuracy conventions and formula sheets are general exam conventions, not from the curriculum map; check them against the confirmed exam board.
  1. Always show the prime factor tree or ladder — method marks depend on it.
  2. Estimate means round to 1 s.f. first; an exact calculation gets no marks.
  3. Check standard form answers have 1 ≤ A < 10.
  4. Fractional index: root first, then power.
  5. Read the command word: 'show that' needs every step; 'write down' needs no working.
  6. Give answers to the accuracy requested; if none is stated, use 3 significant figures for non-exact answers.
  7. Never round in the middle of a calculation; keep full calculator values until the end.
  8. If you get stuck, write down the formula or the first step anyway: method marks are independent of the final answer.
