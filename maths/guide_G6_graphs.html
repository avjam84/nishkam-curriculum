2. Content

G6.1 Line Segments

Key definitionA line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2).

Core knowledge. Length of segment uses Pythagoras: √((x₂−x₁)² + (y₂−y₁)²). This builds directly on the definition above: learn the definition so you can quote it, then practise the technique until it is automatic, because multi-step questions combine line segments with other topics in this block.

What to knowWhat to do in the exam
A line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2).Write the rule or formula first, then substitute, so a method mark is available even if the arithmetic slips.
Length of segment uses Pythagoras: √((x₂−x₁)² + (y₂−y₁)²).Show each step on its own line and check your answer by a reverse operation, estimate or substitution.
ExampleMobile phone tariffs are linear graphs: monthly charge (intercept) plus cost per GB (gradient).
Common mistakePlotting quadratics with straight segments instead of a smooth curve. This is wrong because the correct rule is: A line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2).
Common mistakeForgetting to square negative x values correctly in a table. This is wrong because the correct rule is: A line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2).

G6.4 Harder Graphs: Cubic, Reciprocal, Exponential

Core knowledge. Recognise each shape by its key features: reciprocal never touches the axes; exponential passes through (0, 1) for y = kˣ. 4. Common Mistakes

  1. Calculating gradient as change in x ÷ change in y. Why it is wrong: A straight line has equation y = mx + c, where m is the gradient and c the y-intercept. Gradient = change in y ÷ change in x. Parallel lines have equal gradients.
  2. Plotting quadratics with straight segments instead of a smooth curve. Why it is wrong: A line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2). Length of segment uses Pythagoras: √((x₂−x₁)² + (y₂−y₁)²).
  3. Thinking y = 1/x crosses the axes. Why it is wrong: The graph of y = ax² + bx + c is a parabola. Roots are where the curve crosses the x-axis; the turning point lies on the line of symmetry.
  4. Reading the y-intercept from the wrong axis. Why it is wrong: A straight line has equation y = mx + c, where m is the gradient and c the y-intercept. Gradient = change in y ÷ change in x. Parallel lines have equal gradients.
  5. Forgetting to square negative x values correctly in a table. Why it is wrong: A line segment joins two points; its midpoint is ((x₁+x₂)/2, (y₁+y₂)/2). Length of segment uses Pythagoras: √((x₂−x₁)² + (y₂−y₁)²).

6. Colour-Coded Model Answers

To be confirmed by teacherThe assessment objectives AO1–AO3 and their colour-coding, and the mark allocations shown on model answers, are national GCSE/A level Mathematics conventions, not from the curriculum map.
AO1 Use and apply standard techniquesAO2 Reason, interpret and communicate mathematicallyAO3 Solve problems within mathematics and in other contexts

Question type 1: Calculate / Find 3 marks

Find the equation of the line through (1, 5) and (3, 11).

Show model answer
AO1 — Gradient m = (11 − 5) ÷ (3 − 1) = 6 ÷ 2 = 3.
AO1 — Substitute (1, 5) into y = 3x + c: 5 = 3 + c, so c = 2.
AO2 — Equation: y = 3x + 2. Check (3, 11): 3 × 3 + 2 = 11 ✓.
What makes this workEach step is written on its own line, so method marks (AO1) are earned before the final answer. The last step checks or interprets the result (AO2), which is where full marks are usually secured. The chain of reasoning uses connectives such as "therefore", "which means" and "this shows that".

Question type 2: Show that / Prove 3 marks

Show clearly that the answer to the question above follows from the given information: Equation: y = 3x + 2. Check (3, 11): 3 × 3 + 2 = 11 ✓.

Show model answer
AO2 — State what is given and what must be shown, so the examiner can follow the argument.
AO1 — Gradient m = (11 − 5) ÷ (3 − 1) = 6 ÷ 2 = 3.
AO1 — Substitute (1, 5) into y = 3x + c: 5 = 3 + c, so c = 2.
AO2 — Equation: y = 3x + 2. Check (3, 11): 3 × 3 + 2 = 11 ✓.
AO2 — Concluding statement: this shows that the required result holds, as given.
What makes this workIn a "show that" question the answer is given, so the marks are for the working. No step is skipped, the argument starts from the given facts, and it ends with an explicit concluding sentence.

Question type 3: Explain / Interpret 2 marks

A student made this error: "Calculating gradient as change in x ÷ change in y." Explain why the student is wrong and state the correct approach.

Show model answer
AO2 — The student is wrong because the correct rule is: A straight line has equation y = mx + c, where m is the gradient and c the y-intercept.
AO1 — Correct approach: Gradient = change in y ÷ change in x. Parallel lines have equal gradients.
What makes this workThe answer names the error, gives the correct rule as the reason ("because"), and then states the correct method. Explanations without a reason score at most one mark.

Evaluation

9. Judgement Phrases for Evaluation

In mathematics, "evaluation" means justifying, checking and commenting on answers. Adapt these sentences:

  1. This answer is reasonable because an estimate using values rounded to 1 significant figure gives a result of the same size.
  2. Since the rule for line segments has been applied correctly at each step, the final result follows.
  3. This method is more efficient than the alternative because it reaches the answer in fewer steps with less chance of arithmetic error.
  4. The answer is only an approximation, because values were rounded during the calculation; working to full accuracy would give a more reliable result.
  5. The model assumes conditions that may not hold in reality, so the answer should be treated as an estimate rather than an exact value.
  6. Substituting the answer back into the original problem confirms it, which shows that no error has been made.
  7. Using real-life graphs is appropriate here because the question gives exactly the information that this technique requires.
Reminders

10. Exam Reminders

To be confirmed by teacherReminders about marks, accuracy conventions and formula sheets are general exam conventions, not from the curriculum map; check them against the confirmed exam board.
  1. Gradient = rise ÷ run.
  2. Smooth curves for non-linear graphs.
  3. Know the four standard shapes.
  4. State meaning of gradient with units.
  5. Read the command word: 'show that' needs every step; 'write down' needs no working.
  6. Give answers to the accuracy requested; if none is stated, use 3 significant figures for non-exact answers.
  7. Never round in the middle of a calculation; keep full calculator values until the end.
  8. If you get stuck, write down the formula or the first step anyway: method marks are independent of the final answer.
