M13.2.1 Connected Rates of Change

Key definitionLinking rates using the chain rule: dV/dt = dV/dr × dr/dt.

Core knowledge. Identify the given rate and the required rate first. This builds directly on the definition above: learn the definition so you can quote it, then practise the technique until it is automatic, because multi-step questions combine connected rates of change with other topics in this block.

4. Common Mistakes

  1. Not stating the validity range for binomial expansions. Why it is wrong: (1 + x)ⁿ = 1 + nx + n(n−1)/2! x² + … for rational n, valid |x| < 1. Take out a factor first: (4 + x)^(1/2) = 2(1 + x/4)^(1/2), valid |x| < 4.
  2. Omitting + c before applying conditions. Why it is wrong: Solving dy/dx = f(x)g(y) by writing ∫ 1/g(y) dy = ∫ f(x) dx. Include + c, then use initial conditions to find it.
  3. Using S∞ when |r| ≥ 1. Why it is wrong: Linking rates using the chain rule: dV/dt = dV/dr × dr/dt. Identify the given rate and the required rate first.
  4. Inverting dx/dt ÷ dy/dt in parametric differentiation. Why it is wrong: x and y given in terms of a parameter t. dy/dx = (dy/dt) ÷ (dx/dt). Convert to Cartesian by eliminating t.

6. Colour-Coded Model Answers

To be confirmed by teacherThe assessment objectives AO1–AO3 and their colour-coding, and the mark allocations shown on model answers, are national GCSE/A level Mathematics conventions, not from the curriculum map.
AO1 Use and apply standard techniquesAO2 Reason, interpret and communicate mathematicallyAO3 Solve problems within mathematics and in other contexts

Question type 1: Calculate / Find 5 marks

Solve dy/dx = 2xy given y = 3 when x = 0.

Show model answer
AO1 — Separate: ∫ 1/y dy = ∫ 2x dx.
AO1 — ln|y| = x² + c.
AO1 — y = Ae^(x²).
AO1 — y = 3 when x = 0 gives A = 3.
AO2 — y = 3e^(x²).
What makes this workEach step is written on its own line, so method marks (AO1) are earned before the final answer. The last step checks or interprets the result (AO2), which is where full marks are usually secured. The chain of reasoning uses connectives such as "therefore", "which means" and "this shows that".

Question type 2: Show that / Prove 5 marks

Show clearly that the answer to the question above follows from the given information: y = 3e^(x²).

Show model answer
AO2 — State what is given and what must be shown, so the examiner can follow the argument.
AO1 — Separate: ∫ 1/y dy = ∫ 2x dx.
AO1 — ln|y| = x² + c.
AO1 — y = Ae^(x²).
AO1 — y = 3 when x = 0 gives A = 3.
AO2 — y = 3e^(x²).
AO2 — Concluding statement: this shows that the required result holds, as given.
What makes this workIn a "show that" question the answer is given, so the marks are for the working. No step is skipped, the argument starts from the given facts, and it ends with an explicit concluding sentence.

Question type 3: Explain / Interpret 2 marks

A student made this error: "Not stating the validity range for binomial expansions." Explain why the student is wrong and state the correct approach.

Show model answer
AO2 — The student is wrong because the correct rule is: (1 + x)ⁿ = 1 + nx + n(n−1)/2! x² + … for rational n, valid |x| < 1.
AO1 — Correct approach: Take out a factor first: (4 + x)^(1/2) = 2(1 + x/4)^(1/2), valid |x| < 4.
What makes this workThe answer names the error, gives the correct rule as the reason ("because"), and then states the correct method. Explanations without a reason score at most one mark.

Evaluation

9. Judgement Phrases for Evaluation

In mathematics, "evaluation" means justifying, checking and commenting on answers. Adapt these sentences:

  1. This answer is reasonable because an estimate using values rounded to 1 significant figure gives a result of the same size.
  2. Since the rule for connected rates of change has been applied correctly at each step, the final result follows.
  3. This method is more efficient than the alternative because it reaches the answer in fewer steps with less chance of arithmetic error.
  4. The answer is only an approximation, because values were rounded during the calculation; working to full accuracy would give a more reliable result.
  5. The model assumes conditions that may not hold in reality, so the answer should be treated as an estimate rather than an exact value.
  6. Substituting the answer back into the original problem confirms it, which shows that no error has been made.
  7. Using proof by contradiction is appropriate here because the question gives exactly the information that this technique requires.
Reminders

10. Exam Reminders

To be confirmed by teacherReminders about marks, accuracy conventions and formula sheets are general exam conventions, not from the curriculum map; check them against the confirmed exam board.
  1. + c then the condition.
  2. State binomial validity.
  3. Newton-Raphson fails near stationary points.
  4. Read the command word: 'show that' needs every step; 'write down' needs no working.
  5. Give answers to the accuracy requested; if none is stated, use 3 significant figures for non-exact answers.
  6. Never round in the middle of a calculation; keep full calculator values until the end.
  7. If you get stuck, write down the formula or the first step anyway: method marks are independent of the final answer.
